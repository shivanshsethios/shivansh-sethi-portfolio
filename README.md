# Shivansh Sethi Portfolio

The portfolio leverages various tools and services. Below is a detailed description of the services used:

## 1. **GitHub**
The portfolio's source code is stored and managed in a GitHub repository. It facilitates collaboration, version history tracking, and easy deployment.

## 2. **Sanity.io**
   - **Purpose**: Content management system (CMS).
   - **Role in Portfolio**: Sanity.io is used to manage dynamic content, such as blog posts.

## 3. **Google Analytics**
   - **Purpose**: Website traffic analysis.
   - **Role in Portfolio**: Provides insights into visitor behavior, traffic sources, and user engagement.

## 4. **Calendly**
   - **Purpose**: Scheduling appointments.
   - **Role in Portfolio**: Embedded in the portfolio to allow visitors to schedule meetings.

## 5. **Cloudflare**
   - **Purpose**: Website Hosting ~ Website is made with a (remix + cloudflare) template.

## 6. **EmailJS**
   - **Purpose**: Sending messages from visitors.
